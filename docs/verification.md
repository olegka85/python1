# Проверка версии 0.1 — 11 октября 2026

## Подтверждено

Проверки выполнялись в среде Work на Python 3.12.14. HTTP-сценарии используют
настоящее FastAPI-приложение, SQLAlchemy и отдельную временную SQLite-базу на тест.

- Полный цикл 100 футболок: потребность 140,8 м, дефицит 60,8 м, две приёмки,
  повтор документа, резерв, производство, списание и отчёт выпуска.
- Конкурирующие заказы на последний материал: только один успешный резерв.
- Одновременные запросы с одинаковым ключом: одна запись и одинаковый ответ.
- Нехватка второго материала: полный откат состояния, всех резервов, аудита и Outbox.
- Отмена освобождает резерв; запуск без резерва и повторный выпуск запрещены.
- Сверхприёмка и повтор reference с новым ключом не меняют остаток.
- Метры, округление потерь и запрет дробных штук; отсутствующая рецептура цвета.
- Изоляция фабрик, запрет ссылок на чужие материалы, ограничения ролей и новая
  проверка прав при повторе команды.
- Подписанные тестовые RSA JWT: неверные signature/issuer/audience/expiry и чужая
  организация отклоняются. Сетевой JWKS заменён тестовым адаптером.
- Cerbos: allow/deny, недоступность, некорректный ответ и другой resource ID;
  HTTP-клиент использует MockTransport.
- Inbox не удваивает отчёт; изменённое содержимое с тем же event ID отклоняется.
- Конкурирующие workers, истечение аренды, защита от старого подтверждения,
  retry/backoff, DEAD после ошибок или повторных аварий.
- Readiness без схемы возвращает 503 и не создаёт таблицы.
- OpenAPI включает Bearer security scheme; YAML и Dev Container JSON разбираются.

## Что не подтверждено в этой среде

- Живой PostgreSQL: локальный сервер требует обычного системного пользователя,
  а доступная среда не поддерживает создание/переключение пользователя. PostgreSQL
  тестовый режим подготовлен, но не запускался успешно. Результаты SQLite не доказывают
  поведение PostgreSQL-блокировок и `SKIP LOCKED`.
- Реальная инсталляция Zitadel/Cerbos и ротация её ключей: credentials/environment
  не предоставлялись; проверены адаптеры и криптографическая валидация тестовых JWT.
- Сборка/запуск Docker: Docker недоступен. Проверены исходники конфигурации.
- Миграция Alembic не исполнялась. Код схемы подготовлен как фиксированная ревизия,
  без импорта текущей metadata внутрь миграции.
- Production, внешние публикации, GitHub Actions/CI не запускались.
