# Garment ERP

Python backend для управления производством одежды: материалы, заказы, закупки и выпуск продукции.

Репозиторий инициализирован. Реализация MVP подготовлена в ветке [feat/garment-erp-mvp](https://github.com/olegka85/python1/tree/feat/garment-erp-mvp) для проверки через [pull request](https://github.com/olegka85/python1/pulls) в `main`.
